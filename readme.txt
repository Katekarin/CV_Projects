Welcome!
This repository contains a collection of small projects I created between 2021 and 2023. Each one was a chance to learn something new or experiment with an idea.

All projects are built using HTML, CSS, and JavaScript.

ArcadeArena: A prototype I created to experiment with making a game similar to Vampire Survivors.

Great Wall of China: A very simple informational website. Created out of curiosity – one of my first projects after finishing school.

Karak: A paused project to recreate the board game Karak using HTML, CSS, and JavaScript.

Tic-Tac-Toe: A fantasy-style animated version made in high school. I wanted to write more ‘professional’ code inspired by examples I found online.

Calculator: My first project! I wanted to create something that looked better (at least in my opinion at the time).

Tables: One of my newer projects. A short script that creates a table with random content. It allows sorting (by clicking the header), as well as adding, editing, or deleting rows.
